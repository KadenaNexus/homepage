Where a receipt helps

A receipt shows that a file existed in this exact form at or before a block time on Kadena.

  • Contracts and agreements: show that a signed version existed in this exact form by a given time, for example before a dispute.
  • Designs, code and creative work: timestamp a version before you publish or share it.
  • Reports and records: show that a compliance report or financial record has not changed since it was recorded.
  • Software releases: show which build or source snapshot existed at release time.
  • Offers and term sheets: timestamp the version you sent while a deal is still being negotiated.

No office and no appointment, $0.005 per file. Only the salted fingerprint is sent, never the file, when the fingerprint is made on your side. Anyone can check a receipt against a Kadena node, with no account and without asking us. It is not a notarization: it does not identify who signed or wrote the file, and a receipt whose salt is lost cannot be checked.

Use this verifier without Kadena Nexus

Save this page (it is one file with nothing loaded from elsewhere) and open the saved copy. It needs only the file, the receipt and a Kadena node. The same check as a script, with no dependencies: python3 receipt_proof.py verify <file> <receipt.json>.
