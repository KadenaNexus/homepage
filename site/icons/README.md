# Kadena Nexus product icons

One icon per product, all in the same family: teal tile, orange and white symbol. The parent brand (kadena.ws) keeps the Nexus mark.

| Folder | Product | Site |
|---|---|---|
| `earn/` | Kadena Earn | earn.kadena.ws |
| `marketplace/` | P2P Marketplace | marketplace.kadena.ws |
| `quantum/` | Quantum-Safe Kadena | quantum.kadena.ws |
| `network-monitor/` | Network Monitor | nodes.kadena.ws |
| `devs/` | Kadena Devs | kadenadevs.kadena.ws |
| `adoption/` | Adoption Index | adoption.kadena.ws |
| `garden/` | Kadena Garden | mine.kadena.ws |
| `whales/` | Whale Watch | kadena.ws/whales |

Each folder has:
- `app-icon.png` – 512×512, rounded corners, transparent outside (browser tab icon)
- `app-icon-square.png` – 512×512, full square (wallet and dApp listings; they crop it themselves)
- `apple-touch-icon.png` – 180×180, full square (phone home screen)
- `favicon.ico` – 16, 32 and 48 px

Public URL pattern for listings: `https://kadena.ws/icons/<folder>/app-icon-square.png`
