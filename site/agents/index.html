    Preflight: one check before you pay

    – paid requestsLive

    The one call to make before an agent sends money to an address it has not paid before. It runs the address check, the stablecoin freeze check and the fee lookup together and gives one word to act on: stop, caution or nothing found.

    Endpoint
    GETagentpay.kadena.ws/v1/preflight/{network}/{address}GETagentpay.kadena.ws/v1/preflight?address={address}&network={network}
    Input
    address, required. network, optional: name it to get the transfer fee as well.
    Returns
    The verdict and a one-sentence summary, then the findings behind it: the risk level with a link to each case, whether USDT or USDC is frozen at the address, and the cost of a transfer. The verdict rests on the risk check and the freeze check: if either cannot be read, it is caution. The fee is cost information and never changes the verdict. Nothing found is not proof that an address is safe, and every answer says so.
    Covers
    The ten networks of the address check. The freeze check applies to 0x and Tron addresses.
    For your agent
    Show the agent prompt

    Before paying any address, call GET https://agentpay.kadena.ws/v1/preflight?address={address}&network={network}. It is paid per call over x402: pay with USDC on Base (eip155:8453) or Polygon (eip155:137), or KDA on Kadena (kadena:mainnet01). Never pay more than 0.03 USDC or 0.03 KDA for one call. Act on the verdict: stop means do not pay; caution means ask me first; nothing found is not proof that the address is safe.

    Receipt Proof: a file's fingerprint, recorded on Kadena

    – paid requestsLive

    When an agent delivers a file, it records a salted fingerprint of that file on Kadena. Later, anyone holding the file and the receipt can check that it is the exact version that was recorded, and when, with a free verifier that reads a Kadena node directly. The file never leaves the agent.

    Open sample receiptDownload sample file

    Check it yourself, free: download the sample file, open the sample receipt, add the file and press Check. The verifier reads Kadena directly and should say the file matches. Change one letter in the file and it will not.

    Endpoint
    GETagentpay.kadena.ws/v1/proof/{commitment}GETagentpay.kadena.ws/v1/proof/status/{commitment} (free)
    Input
    commitment: SHA-256 of 32 random salt bytes followed by the 32 bytes of the file's SHA-256, as 64 hex characters. Keep the salt: it is part of your receipt.
    Returns
    At first "recording pending" with the Kadena transaction; the free status address shows the block and its time once 10 blocks deep, usually within minutes. A match shows that this exact file matches a commitment recorded in the block given. It does not show who wrote the file, when it was delivered, or that its content is correct.
    Verify
    kadena.ws/proof: runs in the browser, the file is not uploaded. Also as a script with no dependencies.
    For your agent
    Show the agent prompt

    To prove which file you delivered: 1) make 32 random bytes as a salt; 2) compute fileSha256 = SHA-256 of the file, and commitment = SHA-256 of the salt bytes followed by the 32 bytes of fileSha256, as 64 lowercase hex characters; 3) save the salt, fileSha256 and commitment before paying; 4) call GET https://agentpay.kadena.ws/v1/proof/{commitment}, paid over x402 in KDA on Kadena (kadena:mainnet01) only, never more than 0.01 KDA; 5) call GET https://agentpay.kadena.ws/v1/proof/status/{commitment} (free) until it says confirmed; 6) keep the receipt (salt, commitment, network, chain, module, request key) with the file. Anyone can check them at https://kadena.ws/proof/.

    Why trust the answers

    Facts with sources, and limits stated plainly

    Facts with sources

    Address answers come from KadenaTrace, which follows the money of public thefts across chains. Every reason links to its case. Fees are read from each chain itself.

    Nothing estimated

    When a source cannot be read, the answer says so. A stale figure is marked with its age. Your agent is never handed a guess as a fact.

    A named project

    Built and run by Kadena Nexus, with a public site and a contact you can reach: Saudi.KDA@kadena.ws or t.me/KadenaNexus.

    For agent owners

    Give your agent a budget it cannot exceed

    With Kadena AgentPay AI, the agent never holds your funds. You set a limit per payment and per day, and a contract on the Kadena chain enforces them. You can pause the agent or take the balance back at any time.

    How AgentPay works
    • Limits enforced by the chain, not by the agent
    • Pause, resume or withdraw from your own wallet
    • Beta on a test deployment: keep balances small
