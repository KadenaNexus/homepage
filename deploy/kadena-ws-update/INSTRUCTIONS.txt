2) SAUDI NODE PUBLIC ENDPOINT – so the card shows live figures
   a. GoDaddy DNS for kadena.ws: add A record   node -> 193.122.85.1
   b. On the node (193.122.85.1): install nginx, copy node-kadena.ws.conf to
      /etc/nginx/sites-available/node.kadena.ws, then
        sudo ln -s /etc/nginx/sites-available/node.kadena.ws /etc/nginx/sites-enabled/
        sudo nginx -t && sudo systemctl reload nginx
        sudo certbot --nginx -d node.kadena.ws
   c. Oracle Cloud security list + ufw: open 80, 443 and 1789
      (1789 = Chainweb P2P, so the public crawler can measure uptime)

   Check:
     curl -s https://node.kadena.ws/info                      -> JSON with "nodePackageVersion"
     curl -sI https://node.kadena.ws/info | grep -i access    -> access-control-allow-origin

   After that the card switches from "Online" to "In sync" and shows block height,
   uptime, online since, version and latency. Nothing else on kadena.ws changes.
